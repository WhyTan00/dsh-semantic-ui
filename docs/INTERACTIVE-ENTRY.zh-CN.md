# 免命令打开语义交互

**[打开个人DSH交互视图（本机3200）](http://127.0.0.1:3200/)**

这个入口打开已运行的个人DSH，使用真实语义组件。当前个人环境沿用DSH31，用户无需运行终端命令、安装新插件或新开模型会话。它是本机页面；不是公开网站或Codex原生内嵌视图。其他环境请使用自己已配置的DSH地址，勿将本机端口当作通用在线服务。

## 选择结果并继续

1. 在DSH侧栏打开已有的语义历史消息，展开组件里的“保存与携带完整结果”。个人环境已经有合法的语义/个人模板历史，无需发送新问题。
2. 点击“导入完整结果”，从系统文件选择器选择自己的兼容结果JSON。文件经过原结果格式、依赖和摘要核验后在当前个人配置另存；不覆盖原聊天。可以换成另一份结果，组件随文件内容变化。
3. 在决策视图中点击“回到方案B继续编辑”，修改“条件草稿”，先“预览差异”再“应用到本地试算”。A保持只读，B和草稿独立保留；来源、unknown和本地假设分层显示。
4. 点击“保存双方案到当前配置”或“保存结果到当前环境”。刷新或下次打开后，“读取已保存结果”→选择副本→“打开已保存结果”，继续编辑。要回原历史组件，点击“返回原消息”。

已有示例文件可下载后在文件选择器中选择：[多条件A/B结果](evidence/scenarios/examples/pair.json)、[不同容量条件结果](evidence/codex-result-interop/examples/capacity-returned.json)。这两个文件是公开合成数据；入口不固定加载任何示例，也不替它们认证任意模型说明。用户选择的其他兼容包走同一解析器和组件。

坏摘要、不兼容或非法包会显示中文失败提示并保留当前内容；取消选择不导入。导入的sourceRecord只作历史记录，不提供权限、当前来源认证或动作指令。null、实测0、false、A/B、草稿、主题和保存语言按既有合同携带；显示语言沿用接收端偏好。仅作本地条件变化不会发模型请求，明确的来源补充属于原有独立操作。

项目内的[semantic-ui-view技能](../.agents/skills/semantic-ui-view/SKILL.md)负责给出这个可点击入口与正常界面路径，不要求用户复制CLI命令。技能及中文界面元数据只位于本个人仓库，没有全局安装或修改AI根规则。当前AI根会话新增嵌套项目技能不会自动变成已加载工具；可以显式读取/指向该技能文件。自然技能选择和Codex原生富UI保持未验。

已有31/31.1的只读核对和结果携带仍沿用；本次采用不重装、重发或重启它们，不新建MCP、服务或模型验收。正常入口的新增路径验证、两份不同输入、拒绝/取消及保护记录将在[本次接受](evidence/interactive-entry.json)单列，原模型题失败和预算保持原范围。
