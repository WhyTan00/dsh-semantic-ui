来源明确的条件规则是：**禁止外传时需要离线；该条件不成立时不要求离线。**

| 条件组合 | 在线批注 | 本地批注 |
|---|---|---|
| 禁止外传＋有维护余力（当前） | 不满足离线要求 | 满足离线、维护两项条件 |
| 禁止外传＋无维护余力（假设） | 仍不满足离线要求 | 满足离线要求，但维护条件不满足 |
| 禁止外传条件不成立＋有维护余力（假设） | 离线项不排除；维护需求未知 | 离线项不排除；维护条件满足 |
| 禁止外传条件不成立＋无维护余力（假设） | 离线项不排除；维护需求仍未知 | 维护条件不满足 |

所以，**若小组没有维护余力，而当前禁止外传的条件保持不变，两种方案各有一项明确障碍。** 在线方案由服务方更新，并不能据此认定它无需小组维护。

上述只比较已声明的离线与维护条件，尚不足以确定整体可行性、成本排序或推荐。
