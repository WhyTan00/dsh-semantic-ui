# GenUI 共存的真实模型记录

先读 [紧凑索引](../genui-model-coexistence.json) 和 [成熟度说明](../../MATURITY.zh-CN.md)。

四个初始问题均在新会话中，同时完整启用本插件和公开 GenUI 0.14.0；没有隐藏第三方工具或强制选择。C1/C2/C3 来自冻结题 A1/D2/N1，C4 是目录外的虚构读书会表单。它们测试实际表达选择，同时独立评估内容；选对插件不等于内容正确。

- `C1` 至 `C4` 保留首次结果，包括未通过项。
- `C4-callback` 是原表单的真实刷新与首次提交：未提交内容刷新复位，重新填写后提交；昵称、主题和备注回传至模型第二轮。不是人工用提示词模拟回传。
- `C3-data-facts-followup` 是增加程序数值回执后，同一原题的独立新会话复测；不覆盖 C3 的错误，也不计为一次完整 11 题新轮次。

候选 A/B 虽同为 preview.4，输入 tgz 哈希分别记录。最终发行包还包含这些新增证据与说明，因此不把候选包的哈希冒充最终包哈希。首次输入、实际工具调用/结果和正文完整保留；公开副本替换机器路径与本地会话标识，原件哈希和私有原件保留。截图只包含虚构的组件内容。
