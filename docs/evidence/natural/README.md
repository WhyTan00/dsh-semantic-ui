# 真实模型首次记录

先读 [逐题索引与判断](../../natural-question-results.json) 和 [验证说明](../../VALIDATION.zh-CN.md)。本目录 JSON 为生成的完整验收证据，PNG 为该次回答在真实 DSH 聊天中的组件截图。

- `r1-*`：0.1.0-preview.1，11 题全部首次回答。
- `r2-*`：内部候选 0.1.0-preview.2，同题新会话完整复测。
- `r3-*`：0.1.0-preview.3，进一步修正后的额外完整复测。
- `setup-before-round-2-A1.json`：异步升级未完成时误启动旧版本的额外设置失败，发现后停止，单独保留。

每份 JSON 保留经过路径脱敏的模型可见输入、真实工具参数和结果、拒绝、正文及浏览器观察。原始输入哈希指向私有保留的原件；公开副本替换机器路径及本地会话标识，不包括 HTTP 认证头或凭据。`modelVisibleInputs` 为公开 DSH `llm/stream` 边界，不声称抓取连接器内部 HTTP 序列化。

同一次回答内的工具错误修正属于首次尝试，不能省略。没有人工追加表达提示或答案重试。第一轮控件读取 shadow host 的测量问题已在原回答上重开核对，未重新请求模型。每轮共用一个浏览器上下文，逐题页面错误数组是累计观察；不可简单相加成独立错误次数。

这三轮均不包含 GenUI 生成指引。GenUI 的历史共存为单独的固定公开版本宿主夹具测试；preview.4 的四题真实模型共存和定向复测另见 [共存索引](../genui-model-coexistence.json)，不能与这三轮合并计算通过率，也不可外推为所有问题的模型竞争偏好或用户既有实例验收。
