# 界面语言

preview.26 默认使用简体中文。每个语义组件顶部都有「界面语言」下拉框，可选「简体中文」和「English」。切换会立即作用于同一页面的语义组件，刷新后沿用选择。浏览器禁止本地存储时，本页仍能切换，但无法保证刷新后保留。

中文覆盖架构关系图、决策比较、折线/柱状/直方图、表格、缺失值对照、模板与主题、生成与错误提示、键盘和无障碍说明。统计说明使用现有计算结果，不重新解释或改变数据。选择保存在当前浏览器站点的本地语言设置中，不同步模型、账户或其他设备。

只切换插件固定界面文案。你提供的标题、节点名称、字段名、单位、读数、规则、来源说明与模型正文保留原样；英文来源不会被静默翻译成另一份“事实”。协议、checkpoint、模板和表格的机器标识保持不变。表格显示标题和时间格式随界面语言变化，数据值、单位、缺失mask和计算范围不变。

代码入口为 `src/i18n.ts` 和 `src/locales/zh-CN.ts`，固定文案集中维护；组件用同一语言状态，React Flow和ECharts的可读说明同步更新。语言变更不触发模型请求，不重置当前筛选和本地条件。

开发阶段类型检查及245项单元检查通过；隔离真实DSH的Native/PTC各1组、每组4类视图已验证默认中文、整页同步切换、中英文刷新记忆、保留筛选、存储失败降级、360px无根溢出且pageerror0。第一次测试使用旧协议决策夹具，被现有1.4声明门禁正确拒绝；原失败保留，改用既有合规声明夹具后通过，没有放松运行门禁。旧英文文案测试显式选择English，产品默认仍是中文。
