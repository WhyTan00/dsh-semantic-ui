# 携带完整交互结果

preview.28增加独立的完整结果包。它保存当前组件的数据、规则、本地假设、主题、界面语言和选择，供另一个兼容的个人DSH环境导入后继续使用。原来的模板文件仍只保存字段合同和外观，换数据复用不会带回旧数据或结论。

## 使用

在正常聊天中的任一语义视图，展开「保存与携带完整结果」：

1. 调整好筛选、条件、选择、外观和语言，点击「导出完整结果」，下载`semantic-result.json`。
2. 在另一环境安装本版插件，打开任一语义视图，选择「导入完整结果」。导入先完整校验，然后以新副本保存到该个人环境并显示；旧消息和旧结果不被覆盖。
3. 刷新或以后重开聊天时，展开同一面板，点击「读取已保存结果」，选择结果，再点「打开已保存结果」。它是一份显式保存的结果文档，没有自动替换消息历史。
4. 继续调整后可再次导出，或「保存结果到当前环境」另存新副本。未保存的调整刷新后复位。「返回原消息」恢复原聊天组件。

第一次进入一个全新环境，需要已有一张正常语义视图作为导入入口；本版没有单独的结果管理首页。打开结果可切换组件种类，原消息本身保持不变。结果文档按DSH个人profile隔离，最多20份、总计2MB；可以导出再删除不用的副本。仅删除保存的副本不会改当前视图或旧聊天。

## 保存范围

| 内容 | 结果包 |
|---|---|
| 数据和声明 | 完整版本化view、null、未知值、关系、方案、规则与约束；不补值、不改原始声明 |
| 图表和直方图 | 系列/分组选择、位置范围、表格范围与页码；保留共同分箱、原观测和缺失mask |
| 决策比较 | 本地条件、未应用草稿、关注维度、规则探索开关；未知保持null，探索不成为批准 |
| 架构图 | 选中节点、搜索、邻域聚焦、情景和画布位置/缩放；布局仍由当前容器计算 |
| 外观 | 当前主题、字体、密度、字号、图方向及保存时的中文/英文locale；打开不覆盖读者的当前语言偏好 |
| 来源 | 保存时的有限核对状态、解释与引用，仅作为历史记录；导入不重新认证来源 |
| 模板 | 当前外观和可能存在的模板引用；不包含私人模板库，不把数据装进模板导出 |

临时提示、下载成功状态、折叠面板的开闭和浏览器焦点不属于结果内容。画布坐标可恢复，跨容器的像素排布仍可能改变，可用原来的适配/定位控件继续操作。

## 数据合同与边界

JSON包格式为`dsh-semantic-ui-result`。preview.29新导出版本2，继续读取preview.28的版本1；旧版接收端需先升级才能读取格式2。版本2额外保存独立条件草稿，版本1不能夹带草稿字段，分为`manifest`、`content`和`sha256`。manifest列出生产版本、组件协议、固定renderer依赖、来源记录状态，以及不包含模板库的声明。SHA-256覆盖规范化的manifest和content，用于检测意外损坏；它是可重新计算的摘要，不是作者签名、权限或批准。

整体最多128KiB，沿用现有有限JSON和组件预算；只接受明确的字段、合法引用、有效交互范围、匹配的来源视图标识和兼容依赖。损坏、未知格式/版本、错误选项或依赖不兼容会拒绝，不静默迁移。导入在校验和持久化成功后才显示，存储冲突/失败也不会覆盖旧副本。导入只消费数据，不执行HTML、表达式、指令、工具或模型调用。

导入后的来源状态明确标成「历史来源记录」。即使记录为bound，也不表示当前宿主、来源身份、世界事实或模型自由正文已经核对；来源补充控件不会从导入文件获得调用资格。保存的本地条件仍是假设，原始view和来源记录保持固定。

结果需要兼容的DSH Semantic UI插件和manifest列出的渲染依赖。本版不产生独立HTML，也不打包聊天历史、账户或模型渠道。私人结果只留本地，分享前应检查其中的数据、证据文本和来源引用。
