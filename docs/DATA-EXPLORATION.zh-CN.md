# 本地换数据与双图联动

客户端增量 `0.1.0-preview.31-data.1` 在已有语义消息中增加「用本地数据探索」。不必先让模型生成新图：选择自己的 CSV，明确列和单位后，即可查看原始顺序图、分布图、选中记录表和同范围统计。

## 使用

1. 打开现有个人 DSH 中的一张语义视图，展开「用本地数据探索」，点击「选择本地CSV」。可先使用本仓库的 [观测示例](../fixtures/data-exploration/observations.csv)。
2. 选择「类目或时间列」和「数值列」，填写本文件单位；来源没有单位时勾选「来源未注明单位」。单位不会从列名猜测。选择时间轴还需确认显示时区与来源声明的粒度。
3. 点击「预览映射数据」，核对记录数、单位和前八条记录，再点「应用这份数据」。只有应用成功才替换当前本地视图；原聊天消息不变。
4. 点击原始顺序图上的观测点/柱条，或分布图中的区间，两张图的选中层、记录表、均值、小计与「导出选中记录」一起改变。灰色层始终保留本文件全部记录作参照。
5. 键盘可以使用「选择记录」「选择分布区间」、按显示位置的范围控件或表内的记录按钮完成等价选择。「清除联动筛选」恢复全部；「不选记录」得到真正的空集，不显示伪造的零均值。
6. 展开「保存与携带完整结果」，填写名称并「保存探索到本浏览器」。刷新后从「已保存结果位置」选择「本浏览器的本地数据探索」，读取并明确打开结果。导出完整结果可携带到另一个安装了兼容客户端的浏览器。
7. 再选择 [功率示例](../fixtures/data-exploration/power.csv)，映射「时间」「功率」、单位 `kW`、时区 `Asia/Shanghai`，预览并应用。外观可以沿用；同名映射仅作可见建议，单位仍需确认。新文件替换全部旧观测、选择和解释，不带入旧模板身份、来源认证或模型结论。

取消、损坏文件、非法映射和存储失败都不会覆盖当前结果或旧保存副本。未明确保存的探索刷新后复位。保存副本不会自动改写原消息。

## 数据范围

- 仅接受 UTF-8、逗号分隔的 CSV；最多 128 KiB、500 条非空数据记录、16 列，每单元格最多 1200 字符。表头不能为空、重复或超过 80 字符。支持 BOM、CRLF、引号内逗号、双引号和换行；错误行宽/引号会整份拒绝，不截断取样。
- 数值空格、空单元格、`null`、`NA`、`N/A` 保持缺失，零和负数保留。仅接受有限的十进制/科学计数数字；公式、十六进制、无穷及不能无损往返当前数字表示的值拒绝，不执行表达式或静默四舍五入。
- 类目按来源记录顺序显示。同名类目是不同观测，不隐式求和；图上附来源记录号，表格与下载保留精确原标签。来源记录号按 CSV 记录计数，含表头与被忽略的空记录，引号内换行不是新记录。
- 时间值必须是带明确偏移的 ISO 时间，且代表不同瞬间。显示按时间排序，行身份和来源记录号保留；横向距离表示经过时间。
- 分布区间根据当前文件全部有效值固定，采用 `[下界, 上界)`，最后一个区间含上界。筛选不重新分箱；缺失值没有虚构区间。极端数值无法形成有限区间时明确提示，仍保留表格与未知统计。
- 统计分母是当前选中且非缺失的观测数。有缺失时完整均值仍未知，观测均值/小计另列。JSON 表格下载带相同行 ID、来源文件 SHA-256、记录号、单位、null、统计范围；精确值在表格和下载中保留。

文件仅由显式文件选择读取，不上传或调用模型。只保存映射列的标签/数值、表头、记录位置、文件名和摘要；其他单元格不进入结果。摘要覆盖所选 UTF-8 文件字节（含 BOM），用于区别数据，不认证作者或世界事实。结果仍受原合同 128 KiB 上限约束，超过时拒绝应用，即使 CSV 本身尚在限额内。

## 保存与兼容

新探索使用现有 `dsh-semantic-ui-result` 的格式 **4**，在 `DataChart` 交互状态中增加显式列映射、来源记录位置和唯一选中行 ID 集合；两图、表格、统计与下载都从同一集合派生。格式 1/2/3 原结果继续读取，新客户端对这些结果仍导出格式 3。损坏行引用、旧格式夹带新状态或不匹配映射拒绝，不把新字段灌入旧消息。

格式 4 保存到当前站点/浏览器本地存储，复用原结果库的版本、摘要、20 份/2 MB 限额、冲突检查与新副本语义；写入通过浏览器 Web Locks 串行。禁用本地存储、无锁支持或配额不足时会报错，可导出文件。旧结果仍用原 DSH profile 保存路径；本轮没有改宿主、工具协议、聊天库或 MCP，也没有跨设备同步。选择本浏览器位置只控制读取位置，旧结果的保存按钮仍写其原 profile。

旧版客户端和已冻结的旧只读伴随程序不支持格式 4，需要先升级；回滚客户端不会删除新探索文件或本地存储，但旧版无法打开它们。模板继续只携带字段合同和外观，不携带本地数据、选择或说明。

## 客户端安装

从 [data.1 预发布](https://github.com/WhyTan00/dsh-semantic-ui/releases/tag/client-v0.1.0-preview.31-data.1) 下载 ZIP、`client-manifest.json` 和 `SHA256SUMS`，核对摘要、解压后执行：

```sh
node /绝对路径/解压目录/client-overlay.mjs /绝对路径/个人DSH/profile
```

仅支持 manifest 明确列出的 preview.31 完整运行入口组合、base31 或 prose.1/2/3 客户端。安装器先核对全部运行入口和客户端摘要，只替换当前个人 profile 内的 `client.js` 与许可证文件，原样备份并返回回滚目录，不改宿主或重启服务。回滚使用同一安装器加 `--rollback /绝对路径/备份目录`。

DSH 的客户端热更新会重新挂载组件。安装前先保存现页的本地条件、筛选和草稿；这不是自动保存机制。公开包可供自行安装，仓库发布与当前个人浏览器采用分别记录，见 [本轮证据](evidence/data-exploration.json)。

## 验证边界

使用合成观测与功率文件检查解析、统计、来源行身份、格式往返与失败保留；实际 ECharts SVG 引擎检查类目/时间两类图及空选择。既有个人 DSH 页面中的独立 headless Chromium 检查实际文件选择、点选、区间联动、表格/导出、保存刷新重开、拒绝坏文件与第二份数据替换，并核对 360px 收起侧栏后的容器。

候选脚本仅在自有 QA 页替换资源响应，既有 Edge 页和已安装资产不变；这项验证不等于当前用户页面安装完成、手机或读屏验收。无新增模型调用、DSH 服务或外部端点；新浏览器初始化尝试创建会话在发送前被阻止，数据操作阶段没有此类写入。原六题自然结果保持 0 通过 / 6 失败 / 18 请求，本轮不重判。
