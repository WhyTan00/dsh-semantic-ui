# 说明正文与来源核对

[下载客户端增量与校验和](https://github.com/WhyTan00/dsh-semantic-ui/releases/tag/client-v0.1.0-preview.31-prose.1) · [完整原31宿主包](https://github.com/WhyTan00/dsh-semantic-ui/releases/tag/v0.1.0-preview.31)

在已有 DSH 语义消息中展开 **“核对说明与来源”**，填写完整来源与候选说明，点击 **“核对并生成有据说明”**。也可以直接选择包含这两段文字的 JSON 文件：默认读取 `/question` 与 `/finalAnswer`，支持修改位置。无需运行命令、调用模型或预选固定结果包。

界面默认中文，沿用组件顶部的 **“界面语言 / Language”**；切换不改输入，刷新记住界面语言。原文、单位和来源生成的中文说明不被静默翻译。本功能只在浏览器内计算，不自动保存或上传文字；导出记录会包含你的来源和候选原文。

## 哪些内容可以核对

当前版本只支持既有完整有限中文来源语法：两方案的能力、更新责任、维护需求、资源可用性、未知价格，以及逐项读数、缺失和单位。来源自身必须先被完整解析并通过既有来源校验；可见图表不能代替独立来源。正文支持有限的明确断言，不是任意自然语言理解器。

- **取舍说明**：对照当前需求、资源未知、维护需求和硬性可行性。缺少成本或偏好政策时，不能把可行性升级成整体推荐，不能给未知价格添加月费、币种或成本排序。供应商更新不自动证明团队无需维护。
- **读数说明**：复用 `numericStats`，区分已观测与完整范围、分母、单位、实测零与缺失。显式补零只属于假设。对“无论补什么都会改变均值”构造反例；中位数和告警因果等未实现断言不会被均值检查背书。
- 每项分别显示“来源支持”“仅在明确假设下成立”“与来源或计算矛盾”“来源依据不足”“无法判定”，附候选原文位置、来源 SHA-256、字段/规则及来源位置。JSON 内容还保留准确原始片段与 JSON Pointer，转义文字不冒充逐字原文。
- 没有识别的文字单独保留为未覆盖；从完整来源和确定性规则生成的“有据说明”不会复制它们。即使所有已识别断言通过，也不认证整篇回答、人类身份或现实事实。

例如原 N2 的 `-2、0、缺失、2 摄氏度`，已观测 3 个读数的均值为 0，完整 4 个位置的均值未知。明确假设缺失为 0 时，假设均值也为 0。因此“任意填值都会改变均值”不成立；数值碰巧相同仍不消除缺失。候选说“已观测四个均值为 0”或把摄氏度改成华氏度也不能通过。

修改来源或候选会立即清除旧结论；重新核对绑定新的来源与候选摘要。导出的 `dsh-semantic-prose-review` 格式1与完整交互结果包分开；载入时重新计算，忽略文件里保存的旧状态和旧修订，不把历史状态升级为当前批准。

## 实现与边界

`src/prose.ts` 负责有限断言提取、求值和有据修订；`src/source-reference.mjs` 是从原同步来源构造器抽出的浏览器安全共享实现。来源语法、`decide` 与 `numericStats` 沿用既有代码，没有另写一套业务算法。`ProseReviewPanel` 接入正常 `SemanticView`，所有输入变化与异步结果通过同一序列绑定，过时核对不会覆盖新输入。

本功能不会拦截或改写组件外其他 assistant 正文，也没有改变 GenUI、DSH 会话协议或结果包格式。它补上插件自己可控的“输入候选→核对→生成有据说明”路径；仍不能保证任意模型未来输出完全正确。原六题自然模型结果继续保留为 **0通过 / 6失败 / 18请求**，本次新增模型请求、MCP连接和服务均为0。

## 客户端增量包

发行标识为 **`0.1.0-preview.31-prose.1`**，只更新客户端与随附许可证，兼容冻结的 preview.31 宿主及 DSH `0.2.1-rc.2`；不是新的完整宿主包，也不冒充原31安装后所有字节仍相同。源码的完整构建会包含此功能。

下载同名客户端 ZIP 和 `SHA256SUMS`，先核对摘要并解压。在已正常安装原31的**个人独立配置目录**上执行：

```sh
node client-overlay.mjs /absolute/path/to/your/personal/profile
```

这里填写包含 `node_modules/@whytan/dsh-semantic-ui` 的个人 profile 目录，不是仓库或共享包目录。安装器核对原宿主与客户端摘要；拒绝其他修订、损坏文件及指向共享 pnpm store 的链接。写入前在该 profile 私有备份旧客户端，原子替换打断硬链接；不读取模型凭据、不改配置、不重启宿主。DSH 自带客户端更新通道发现变化后刷新页面即可。

回退使用安装器实际返回的备份目录：

```sh
node client-overlay.mjs /absolute/path/to/your/personal/profile --rollback /absolute/path/to/returned/backup
```

安装器拒绝覆盖其他已变化的版本。采用及回退都只处理两个客户端文件。构建者可用 `node scripts/pack-prose-client.mjs` 从已提交干净源码生成客户端包；前提是本地保留不可变的原31归档与清单。该命令不启动服务或模型。

本次新增代码的离线单元、原始 D1/N2 正文复核、来源修订和正常个人 DSH 页面接受证据见 [回执](evidence/prose-review.json)。无新增 Linux、PTC、用户 Edge 视觉或真机验收；旧完整语言矩阵仍按原版本记录，不外推成本次增量包的测试。
