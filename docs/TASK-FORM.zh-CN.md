# 可复用任务表单

客户端增量 `0.1.0-preview.31-task.3` 补齐“声明输入要求 → 填写草稿 → 核对预览 → 明确确认 → 保存后继续”的本地流程。它支持布尔、数值、枚举与普通文本，复用现有条件解析、有限规则、主题和结果库；不是另一个模型调用层。

## 直接使用

从 [task.3 预发布](https://github.com/WhyTan00/dsh-semantic-ui/releases/tag/client-v0.1.0-preview.31-task.3) 下载单文件 `task-form-0.1.0-preview.31-task.3.html`，在自己的浏览器打开即可。页面内嵌固定脚本/样式，没有外部资源或网络连接，不需要启动服务、登录、模型密钥或安装到当前 DSH。请用同页 `SHA256SUMS` 核对文件。这个新入口与您已有 DSH 页独立，HTML内含本项目及React、ReactDOM、Scheduler、Zod的完整许可证。

1. 可点击「载入公开示例A」熟悉流程，或「用同一模板开始新任务」。新任务保留字段、规则与主题，答案全部清空。
2. 填写本地来源文字和各字段。必填未知会阻止预览；可选未知原样保留。数值必须注明单位，零、否、未知分别显示；超出模板范围、非法枚举、公式或不能无损表示的数值拒绝。普通文本只当文字，最多800字符。
3. 点击「预览本地结果」，核对明确输入与每条规则的满足/不满足/未知。编辑答案、来源、模板或外观会撤销旧预览；确认前必须重新预览。
4. 勾选「我已核对这份预览」，再「确认并另存为本地结果」。成功保存后才显示保存完成；旧副本不覆盖。规则不满足或可选条件未知仍可作为记录保存，确认不会把它们变成通过。
5. 以后点击「读取已保存任务」并明确打开，或「打开任务结果文件」。继续修改后再次预览/确认会形成新修订，引用父确认摘要；从旧修订继续可以形成分支，不伪造全局唯一线性历史。
6. 「保存未确认草稿」可保留非法字段文字和缺失来源，重开后继续补。取消预览保留填写内容和旧保存副本。「导出当前草稿」与「仅导出这次确认」分别携带相应状态。

来源文字和答案都由用户显式提供。程序没有自动认证来源到字段的翻译、来源身份或世界事实；规则只依据这份模板和字段计算，不执行脚本、字符串表达式或导入文件中的指令。**本地确认不是模型接受、账号权限、业务批准或外部提交。**

## 模板与外观

「复用与编辑模板」支持明暗/配色选择、纯模板导出和显式文件导入。主题改变会提高模板修订并撤销预览，当前答案保留。纯模板包含字段类型、必填、单位/范围、枚举选项、提示、有限规则和外观，没有答案、来源文字、确认或结果。用它开始第二份任务时答案全部为空。

高级结构编辑使用白名单 JSON：最多12字段、每个枚举12选项、24条规则、每规则12条比较；仅允许 `eq/ne/gt/gte/lt/lte` 与 `all/any`。普通文本/枚举/布尔仅能等于或不等于；大小比较仅用于数值。ID/引用/类型/单位受严格校验。同一模板结构或规则变更须提高revision，过期版本不能替换当前版本；未应用的模板文字编辑会阻止新预览，可恢复已应用版本。

也能显式选择原有 `dsh-semantic-ui-template` 的 DecisionExplorer 字段/外观导出文件：转换后保留字段、单位、枚举与主题。旧合同未声明任务必填或规则，因此不会猜测，字段先设可选、规则为空；没有单位时明确显示“未注明”。其他组件模板不会伪装成任务表单。转换后可编辑并导出新任务模板，原私人模板库不会被读取或修改。

## 保存、兼容与失败行为

任务附录使用原 `dsh-semantic-ui-result` 的格式 **5**，记录模板/来源及其修订、原始草稿、父确认摘要、明确确认时间与预览摘要。原有1/2/3/4仍按原合同读取和导出；旧冻结客户端/伴随程序不支持5，需使用本版入口。校验会重新计算确认摘要和有限结果，损坏或降级夹带新字段拒绝；摘要检测变化，不是签名或权限证明。

复用同一个 ResultLibrary：最多20份、总计2MB，单结果仍最多128KiB/12层。新任务使用独立的浏览器存储键，避免旧宿主不认识格式5，也不访问旧数据探索、聊天或私人模板库；写入通过Web Locks串行并检查版本。存储冲突、配额不足或保存失败不发布成功状态、不覆盖旧确认。只删除明确选中的新任务副本。

本地文件页面能否持久化浏览器存储由浏览器决定。禁用本地存储或无Web Locks时，可「导出当前草稿」或勾选后「仅导出这次确认」，以后显式打开文件继续。刷新会丢失未保存编辑；没有自动保存、跨设备同步、身份认证或外部动作。

## 直接文件命令

ZIP包含无需依赖安装的 `task-form.mjs`（Node24+）与公开合成文件。命令只读明确指定的文件，输出以新文件创建，不覆盖旧文件：

```sh
node task-form.mjs preview --template examples/task-template.json --source examples/source-a.json --answers examples/answers-a.json --out preview-a.json
node task-form.mjs confirm --template examples/task-template.json --source examples/source-a.json --answers examples/answers-a.json --preview preview-a.json --ack-local --out result-a.json
node task-form.mjs inspect --result result-a.json
```

修改自己的来源版本/答案文件后，preview与confirm同时加 `--continue-from result-a.json` 可创建下一修订。旧预览、缺少 `--ack-local`、同一来源ID降版本或改文字而不升版本会拒绝。`draft`保存未确认草稿；`blank`从模板生成全未知答案；`template-from-result`只导出结构/规则/主题。所有命令都没有模型、工具或网络执行。

`examples/synthetic-confirmed-a.json` 是固定时间/ID、由确定性明确ack夹具生成的公开示例，不是某位真人对实际任务的确认。示例A保留0/false/unknown，规则结果为满足/不满足/未知；新任务B为120 GiB/云端/true/80元每月，得到不满足/满足/满足，没有继承A的答案。

## DSH 客户端增量与当前边界

ZIP也包含 `client.js`、清单和原客户端安装器。兼容清单列出的完整base31/已知host增量组合及base31、prose.1/2/3、data.1客户端；仅在用户选定的个人profile替换客户端/许可证，并提供精确回滚，不改宿主、工具、MCP、聊天或模型配置。安装后可在普通语义视图展开同名任务入口；任务结果导入保存到任务浏览器库，旧结果路径保留。

**本轮没有在当前个人profile执行安装，也没有浏览器访问、导航、热更新或重挂载。** 当前Edge未保存状态和两项旧等待保持；不要因本版已发布就推断现页无草稿或已升级。以后满足原保护条件再使用安装器，单文件入口当前可独立交付。

本轮验证为类型/必要回归、实际打包命令的预览→确认→文件保存→重开→新修订→旧文件保留、反例拒绝，以及真实React组件的非浏览器静态输出。未运行浏览器/DSH Native/PTC/视觉、手机或读屏验收；不将构建和命令检查冒作这些结果。新模型/MCP/服务/远端CI均0，原六题0通过/6失败/18请求不改。详细分层结果见 [本轮证据](evidence/task-form.json)。
