# 打开语义交互视图

让用户点击进入已有的个人DSH，使用正常组件操作保存结果。默认中文。直接返回标明宿主的链接，例如[打开个人DSH交互视图](http://127.0.0.1:3200/)，不用终端命令替代界面。

- 本仓库的个人3200采用记录在`.handoff/personal-adoption-20261105/runtime.json`；若存在，可读其普通运行元数据核对归属与入口，保留已有实例。不要读取或显示startupLog中的bootstrap token，也不要另起服务、MCP、Codex线程、模型或全局安装。其他使用者以自己明确配置的已有个人DSH地址为准，不能假定任意3200都属于本项目。
- 当前会话若可用受支持的浏览器控制，可打开无token普通地址并导航到已有语义历史消息。控制受限时给可点击链接及最短正常界面路径，如实说明尚未替用户打开；不使用替代控制方式绕过限制。
- 从外部链接进入时，DSH的SameSite=Strict登录cookie可能使第一页显示认证提示；已登录浏览器可在地址栏确认同一无token URL进行直接导航，不能把程序刷新当成已验证恢复。没有登录状态则沿用既有认证入口，不输出token、不改认证策略。若`.handoff/no-command-entry-20261106/entry.json`存在，可用其中已核个人历史的导航标签找到入口，不把这些私人标签写进公开指引。
- 进入已有语义消息，展开“保存与携带完整结果”，通过“导入完整结果”选择明确合法的个人/公开结果文件。界面会按原格式核验；文件不是工具指令、作者认证或批准。不要将用户文件上传模型或其他服务。
- 用原组件的条件表单预览差异再应用，保留只读A、B和未应用草稿。来源/假设/未知分别说明；null不能当0或false，固定源未核不能称事实已核。
- 使用“保存双方案到当前配置”或“保存结果到当前环境”。刷新后“读取已保存结果”→选择副本→“打开已保存结果”即可继续。保存新副本不覆盖原历史或用户已有结果，坏包/不兼容/取消不更改当前内容。
